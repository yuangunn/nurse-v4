사전입력
  1. 표 위 카드 3~4장(월 배너·범례·안내·신호등) → 툴바 한 줄의 신호등 문장 하나. 범례는 셀 팝업이 대신함.

  3. 버튼 11개 → 7개(메모 표시는 더보기로). 되돌리기는 항상 같은 자리, 변경 직후 토스트.
셀 팝업 · 붙여넣기
  1. 17코드를 ‘근무 / 휴무·휴가’ 두 묶음, 코드+이름 44px 버튼. 키보드 힌트 한 줄.
  2. 잠금·메모·지우기를 팝업 하단에 고정 — 우클릭을 못 찾아도 됨.
  3. 붙여넣기 모달은 종류 3택(사전입력·위시·완성표) + 인식 결과 한 문장 + 버튼 ‘표에 넣기’.

  3. 요약·리포트 두 패널 → 표 아래 서랍 하나(탭 7). 표시 옵션 4개는 더보기로.

  1. 카드 4장 그리드 → 왼쪽 메뉴(자주 3 / 거의 안 바꾸는 3) + 한 화면 한 목적.
  2. 명부가 첫 화면. 처음이라면 안내 한 줄 + 엑셀 템플릿 버튼(T1 5분).
  3. 줄마다 ⋯/× 아이콘 → ‘편집’ 글자 버튼. 삭제는 모달 안에서 두 번 확인.
간호사 모달 · 폰
  1. 모달은 기본(이름·그룹·성별·가능 근무·야간전담·주휴 요일)만 보이고 특수 사항 3종은 접힘.
  2. 폰 오늘: ‘내 근무’ 카드가 맨 위, 근무자 이름을 근무별 칩으로. 편집 도구 없음.
  3. 폰 근무표: 내 줄 강조 + 필터 칩(전체·내 근무만·그룹). 더보기는 목록 6개.
