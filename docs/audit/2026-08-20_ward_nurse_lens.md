## 1. 조사 렌즈 (병동 근무 짜는 간호사의 눈)

| 렌즈 | 질문 |
|---|---|
| **L1 원티드 존중** | 사전입력은 사실인가? 못 지킬 때 무엇을 먼저 뒤집나? 휴무 원티드(제사·결혼·외래 동행)가 근무 원티드보다 보호되는가? 뒤집혔으면 사람이 알 수 있는가? |
| **L2 한 사람의 한 달** | 쉴 때 붙여 쉬는가, 퐁당퐁당은 피하나, 야간 뒤에 충분히 쉬나, 수면오프를 만들지 않나, 연차를 멋대로 쓰지 않나 |
| **L3 공정성** | 야간·주말·공휴일·차지 부담이 고르게 도는가? 위시가 계속 거절되는 사람이 없는가? 나이트킵 순환은 공평한가? |
| **L4 병동 규칙(제1원칙 1~8)** | 각 원칙이 엔진·배점·화면·문서에 일관되게 들어가 있는가 |
| **L5 투명성** | 왜 이 근무가 나왔는지(배점 상세), 왜 원티드가 안 됐는지, 오프특근·완화가 누구에게 갔는지 보이는가 |
