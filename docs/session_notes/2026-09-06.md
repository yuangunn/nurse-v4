## 사용자에게 보고할 이탈·판단
- 검사 기준 뷰포트는 디자인이 준 **1920×1080** — 병동 1366×768 은 레이아웃만 확인(백로그 M8).
- spec 수정 11곳(13px→14px 1, 구조 셀렉터 10) · 검사기 수정 2 — 모두 `$comment`/주석.
- 폰 편집 도구는 핸드오프의 "완전 제거" 대신 더보기에서 켜는 토글로 유지(`data-rd=phone-edit-tools` 없음 = 검사 통과). 기능 손실 방지.
- 간호사 삭제 툴팁의 "60일 안에 되돌릴 수 있어요"(copy.json)는 실제 기능이 아니라 넣지 않았다 — 저장본 캐스케이드 정리가 즉시 일어난다.
- 게스트 시드 이름 앞 `*` 는 데이터(예시 표시)라 화면에서 손대지 않았다.
- 프로필 화면·온보딩·도움말·분석 화면은 핸드오프 범위 밖 — 토큰 재매핑만.
