## 요청
1. 병원 병동 = 61·71·81·82·91·92·101·102·111·112·121·122·131·132. 병동 번호는 **층 + 라인**이고 병실은
   층×100 + 호수 — **1라인 1~14호, 2라인 51~64호**(92병동 → 951~964). 관리에서 병동을 고르면 병실이 쫙 뜨고
   병상수만 입력하게. 91병동 엑셀에 `901, 902`로 나오던 것을 `1, 2` / `1~2`로 일원화.
2. 크롬을 껐다 켜거나 PC를 재부팅하면 파일 연동이 풀려 매번 다시 걸어야 함 → 데이터를 **외부(공유 파일)**에
   둘지 **HTML 안**에 둘지 고를 수 있게.

- **보관 방식 2종** (`localStorage assignMode` = `file` | `local`):
  - 공유 파일(기존) — 사이드카 자동 읽기 + 파일 핸들.
  - **이 컴퓨터 안** — IndexedDB `local` 키(+localStorage 예비 사본). 파일·권한창 없음, 공유 안 됨. 부팅 순서
    native → **local** → silentReattach → sidecar. 시작 화면 [이 컴퓨터에만 보관하고 시작](데이터 있으면 “이어서”),
    관리 > 데이터 보관에서 [이 컴퓨터 안으로 옮기기] / [공유 파일로 옮기기]. 로컬 모드에서 백업 드롭 = 확인 후 교체.
    파일을 열면(`useHandle`/`openSidecar`) 모드가 `file`로 바뀌어 로컬이 파일보다 먼저 뜨지 않는다.
  - 브라우저는 자기 HTML 파일을 고쳐 쓸 수 없어(파일 권한 문제 동일) “HTML 안 보관”은 브라우저 저장소로 구현.
- **재연결 마찰**: 브라우저는 닫았다 켜면 쓰기 권한을 잊지만 핸들은 IndexedDB에 남아 있다.
  `reattachHandle(h)` = 사용자 동작 안에서 `requestPermission`만(파일 창 없음) → 파일 rev 비교 → 안 바뀌었으면
  지금 화면(읽기 전용 중 고친 것 포함)을 그대로 잇고 즉시 저장, 다른 PC가 먼저 저장했으면 파일로 갈아타고 안내.
  `connectSave()`가 먼저 시도하고, `touch()`의 **첫 편집**에서도 1회 자동 시도(`navigator.userActivation`).
  거부하면 읽기 전용 유지(`__reattachDenied`). Chrome 122+의 “모든 방문에서 허용”이 붙으면 `silentReattach`가
  0클릭이 된다(파일:// 에서의 동작은 실측 필요).

## 2차 — 시니어리티 드래그 · 신규 간호사 붙이기 · 양식 문구 편집 · 연속성 가중치 수정 (v260916b)

### 요청
1. 도움말 그림은 **모든 수정이 끝난 뒤** 사용자가 말할 때 찍는다 (중간에 찍지 말 것).
2. 간호사 관리에서 드래그로 순서 = 시니어리티. 이유: 같은 날 차지 가능한 사람 중 **가장 위가 차지**.
3. 신규 간호사: 근무 `/D /E /N`(인원 제외), 배정표에서 간호사 이름을 눌러 그 신규를 뒤에 붙임, 엑셀은
   줄바꿈 `지원근⏎/ 안소미`.
4. "5~10 본 사람이 다음날 6~9가 아니라 5,10,11을 보는" 이유 → 알파벳(라벨) 기준 아니냐는 의심 포함.
5. 병실 배정표(양식)를 HTML 안에서 편집할 수 있는지.
6. 기준 해상도 1920×1080.

### 원인 (4) — 코어 `maxMatch` 는 겹침 **총합**을 최대화
- 재현: X 어제 D 3인 B(5~10), W 어제 E 4인 C(6~10)→오늘 D(원칙2) / 또는 W 이틀 전 C, 어제 OF(원칙3).
  오늘 5인: X→C(5,10,11)+W→D(6~9) = 2+4 = 6 > X→D(4)+W→C(1) = 5 → **X가 밀린다**. 라벨 폴백(b)이
  아니라 방 기준 매칭(a)의 점수 구조 문제. 등급 가중(10^10/10^9)은 '앉느냐'만 정하고 방 선택엔 무력.
- 수정: 사전식 가중 `SEAT_W=[1e15,1e14,1e13]`, `OV_W=[2e10,4e7,8e4]` — 앉는 수(등급별) > 원칙1 겹침 합 >
  원칙2 > 원칙3 > 최근·선임. 후보 ≤5·겹침 ≤99 라 2^53 안. 등급 안에서는 여전히 합산이라 "무차별한
  전일 근무자가 비켜 주는" 성질 유지. 겹침 단위를 **병상수 합**(`opts.bedsOf`)으로 — standalone 이 병실
  목록 병상수를 넘긴다(모르면 1). 회귀 3종(근무변경·오프복귀·병상수) 추가, 기존 테스트 전부 통과.
