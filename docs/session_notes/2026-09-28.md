## 교차 검토 (세 갈래 — xlsx 온전함·채우기 정확성·화면 흐름)
재현된 13건을 고치고 로직 30b·30c·30d 에 넣었다(고치기 전 코드로 돌리면 자리 줄·채우기 10건, 글자 고치기 6건 실패):
- **한 줄 구역** — 102 에서 N 을 한 자리까지 뺐다 넣으면 같은 자리가 두 번 찍히고 한 사람이 빠졌다(구역 이름 병합이 한 줄이라 구역이 늘지 않음).
  → 구역은 두 자리 아래로 빼지 않는다.
- **구역 안 굵은 선** — 두 자리 구역에 넣으면 첫 줄(굵은 윗선)을 본떠 구역 안에 굵은 선. → 처음 양식의 같은 순번 안쪽 줄을 본뜬다(뺐다 넣으면 처음과 같다).
- **자리 이름 열** — 101 에서 네 줄을 빼면 표 아래 B열 블록이 이겨 모든 구역이 0자리, 다시 넣지도 못함. → 가장 위에서 시작하는 열.
- **줄 수식** — 줄마다 제 줄을 세는 수식이 새 자리 줄을 가리킴. → 끝 줄 글자를 옮길 때 수식도 옮긴 만큼.
