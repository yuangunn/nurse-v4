# 2026-09-28 — 어싸인 배정표 머리줄을 사용자 시안대로 (결정 2-37)

## 요청
"위의 헤더 디자인을 이렇게 바꿔줄 수 있어? 이게 조금 더 명확한 것 같아서." — 시안 그림 한 장:
왼쪽 `어싸인 배정표` + 회색 알약 `101병동 · 병실 14 · 간호사 14`, 가운데 탭 `배정표 / 근무표 / 관리`,
오른쪽 초록 알약 `● 저장됨 · 14:02`, `◐ 화면: 자동`, `도움말`.

## 한 일 (`standalone/assign.html`)
| 전 | 후 |
|---|---|
| 오른쪽 끝 글자 단추 배정표·근무표 고치기·⚙ 관리 (다른 단추와 같은 무게) | 가운데 탭 셋, 켜진 탭은 흰 바탕. paste → 근무표 탭, day → 배정표 탭 |
| 파일 칩 = 경로+파일명, 끝에 저장 상태 | 저장 상태 알약 — `저장됨 · 14:02`(초록) · `저장 중…`(회색, 점 깜빡임) · ⚠ 첫 구절(빨강) · 읽기 전용(노랑). 경로는 툴팁·클릭 복사 |
| 오른쪽 아래 떠 있는 동그란 `?` | 머리줄 [도움말] (F1 그대로) |
| 테마 단추 아이콘만 | `◐ 화면: 자동/다크/라이트` |
| flex 줄바꿈 — 좁으면 높이가 상태마다 달라짐 | grid 세 칸, 1024px 이상 한 줄 60px, 병동 칩만 말줄임. `--tbH` 로 옆 열 sticky |

- 근무표 고치기 화면에 [새 근무표 넣기] — 탭으로 들어온 사람이 넣기로 가는 길.
- 알약이 '저장됨'이라 말하는 조건을 좁혔다: `dirty`(0.7초 모았다 쓰는 동안)면 '저장 중…'. 저장 실패는 어느 길로 부른 저장이든 알약에 남는다.
- '⚙ 관리' 35곳 → '관리', 도움말·투어·마법사 끝 문구의 '오른쪽 아래 ?' → '맨 위 오른쪽 도움말'. 투어 look 에 근무표·관리 탭과 도움말 단계.
- 1920 다크에서 켜진 탭이 눌린 것처럼 보여(카드가 바탕보다 어둡다) 한 단 밝게.
