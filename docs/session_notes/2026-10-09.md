# 2026-10-09 — 어싸인: 간호사 그룹 · 그룹원끼리 인계 피하기

## 요청
"현재 어싸인 배정은 갓 독립한 신규간호사 - 신규 간호사 간 인계가 가능해. 간호사관리에서 간호사 그룹을 만들고 특정 그룹은 서로 D-E, E-N, N-D
인계가 가능하지 않게(최대한 어싸인이 겹치지 않고 회피하게) 해줄수있어? 이것도 원칙 설정에 넣어서 어느 그룹의 그룹원간 인계를 피할지도 정할 수 있게 해줘."

## 만든 것 (결정 2-46)
- **코어** `assign-core.js` — `opts.handoverGroups={id:[그룹]}`. 앞 근무(D ← 전날 N · E ← D · N ← E)에서 자리에 앉은 같은 그룹 사람이 본 병상을
  넘겨받는 양(병상수 합)을 마지막 다듬기·CRN 자리 고르기의 비용에 넣었다 — 주지 않을 방 다음, 원칙 1~3 보다 먼저. 차지·손 자리·고정 차지는 그대로.
  피하지 못한 인계는 `byDay[날][근무].handover=[{from,to,rooms}]`.
- **화면** `standalone/assign.html` — 간호사 관리 [＋ 그룹 만들기] · 그룹 띠 · 그룹 칸 칩, 배정 원칙 맨 아래 '그룹원끼리 인계 피하기' 그룹마다 스위치,
  배지 '3켬 · 그룹 1', 확인 카드 '같은 그룹 인계' 안내(그룹마다 한 줄), 도움말 주제·투어, 이름 바꾸기·지우기·되돌리기·저장·옛 파일(`normGroups`).
- **설명서** 22 → 24쪽 (7~8쪽 '신규끼리 인계 피하기', 20쪽 확인 카드 표, 24쪽 요약).

## 만들면서 고친 것
- 확인 카드가 길었다 — 짝마다 한 줄 + [배정 원칙 열기] 단추. 2인 N 의 E → N 처럼 피할 수 없는 인계가 주마다 쌓였다. 그룹마다 한 줄 · 넷 넘으면 [n건 더 보기] ·
  까닭은 끝에 한 번 · 단추는 차지 자리 탓일 때 방 구성만.
- 다른 소속(82 SU)이 된 그룹원 — 그룹 띠 인원에 세였고 그룹 칸이 '—'라 뺄 수 없었다. 병동 그룹원만 세고, 그룹원이었던 그룹 칩은 남긴다.
- 그룹 칸이 생기면 1280·1366 창에서 간호사 표가 옆으로 밀렸다(칸 너비가 최소 너비로 쓰인다). 남는 폭에 맞춰 그룹 칸 → 가능 근무 → 이름 칸 순으로 줄인다.
