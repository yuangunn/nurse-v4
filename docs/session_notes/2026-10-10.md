# 2026-10-10 — 어싸인: HTML 안에서 예시 파일 받기

## 요청
- 원근: "예시파일은 js라서 html에서 다운로드는 지원하지 않는거지? 인트라넷에서 시연용파일을 html내에서 다운로드할 수 있는 방법 없을까? 그냥 하드코딩 해도 용량 별로 차지 안할거같은데 불편하려나?"

## 한 것 (결정 2-49 끝)
- 예시 카드와 예시 중 관리 > 데이터 보관에 [예시 파일 받기] — `downloadExample(병동)` 이 `makeExample` 로 그 자리에서 `<병동>병동 예시.js` 를 만든다.
- 하드코딩하지 않은 까닭: HTML 크기 그대로(14개 박으면 약 230KB), 날짜가 받는 날 기준으로 따라간다(박은 파일은 날짜가 굳는다), 예시에서 고친 것은 안 든다.
- 받은 파일은 `example` 표시가 있어 끌어 놓기·[데이터 파일 열기]로 열어도 예시로 연다(저장 안 됨).
- 도움말 '예시로 둘러보기' 팁, 설명서 4쪽 팁·캡처(25-example) 다시.

## 검사
- 로직 39절에 내려받기(이름 · 내용 = makeExample 그대로 · 이번 주 · 고친 것 안 듦 · 받아도 예시 그대로) — 637건 통과.
- e2e 77건 통과(이 컨테이너에서만 실패하는 xlsx 내려받기 이름 1건 제외), 예시 파일 `--check` 14개 그대로.

# 2026-10-10 (밤) — 어싸인: 처음 설정의 '예시' 단계 · 예시 수정 띠 (결정 2-50)

## 요청
- 원근: "그러면 아예 온보딩으로 할때 병동 고르고 예시파일로 어떻게하는지 알아보기를 유도해보는건 어때? 예시파일로는 자동연동안되게 예시파일 다운로드 받았을때만 하고
  예시파일로 수정할때는 위에 알림 뱃지를 띄우는거야. 예시파일 수정중으로 연동이 되지 않는다는 내용을."

## 한 것
- 마법사 병동 단계 뒤에 **예시** 단계 — [○○병동 예시로 해 보기 ▶] · [다른 병동 예시] · [예시 파일 받기] · '예시 없이 다음 ▶'. 해 보면 예시 카드와 띠의 주 단추가
  [처음 설정 이어 하기 ▶] — 우리 병동 파일로 돌아와 방 구성 단계부터.
- 예시에서 처음 고치면 머리줄 안 노란 띠 '예시 파일 수정 중 — (우리 병동 파일과 | 어느 파일과도) 연동되지 않습니다' + [처음 상태로] · [예시 끝내기 | 처음 설정 이어 하기 ▶].
  화면 상태(투어 봄·인쇄함)는 고친 것으로 치지 않는다.
- 연동 막기 다짐: `_writeStore` 가 저장 도중 예시가 열리면 멈춘다(예시 내용이 우리 파일로 들어갈 수 있던 틈), `enterDemo` 가 진행 중 저장을 기다린다, 예시 중 저장 연결·다시 읽기·다른 위치 저장 막기,
  예시 파일인지를 '버릴까요?' 전에 본다, 예시 중 창 닫기는 우리 파일에 저장 안 된 것이 있을 때만 묻는다, 우리 파일이 열려 있으면 [우리 병동 파일 만들기]를 숨긴다.
- 도움말(처음 안내 · 예시로 둘러보기), 설명서 3·4·26쪽 문구와 25-example 캡처(띠가 보이게).

## 검사
- 로직 39·40절 653건, e2e 1a·2a 84건(이 컨테이너에서만 실패하는 xlsx 내려받기 이름 1건 제외), 예시 파일 `--check`, 호환 43건, 실시간 수정 씨앗 1.
- 교차 검토(넷 중 둘에서 끊음 — 이 컨테이너가 2개씩만 돌려 4시간이 걸렸다): 처음 설정 창이 예시 위에 남는 길, 예시 중 다른 파일을 열면 기억해 둔 파일을 버리는 길,
  쓰던 칸의 값이 예시 ↔ 우리 파일로 새는 길 — 셋 다 고치고 검사를 붙였다. 고친 것 다섯을 하나씩 되돌려 보니 검사가 다섯 다 잡았다.
