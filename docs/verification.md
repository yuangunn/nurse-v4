# 어싸인 배정 검증 절차

어싸인 배정표(`standalone/assign.html`)가 **배정 원칙과 차지를 정말 지키는지**를 사람이 화면을 눌러 보지 않고도 매번 확인하는 절차다.
2026-10-01 사용자 요청("다른 원칙들도 지금 안지켜지는게 있는거 아니야? … 이런 일이 다른 병동에도 없을까? 실증 및 검증 절차가 필요할거같아")으로 만들었다.
배경과 그때 찾은 문제는 결정 2-43.

원칙이나 서식·배정표 화면을 바꾸는 PR 은 아래 검사가 모두 통과해야 머지한다. 둘 다 CI(`.github/workflows/test.yml`)에서 돈다.

| 검사 | 무엇을 | 시간 |
|---|---|---|
| `node scripts/test_assign_principles.mjs` | 배정 엔진을 정답과 견준다 (원칙 ①~④ · 차지) | 약 20초 |
| `node scripts/test_assign_core.mjs` | 손으로 짠 사례 (병동에서 실제로 있었던 일) | 1초 |
| `CHROME=… node scripts/test_assign_logic.mjs` | assign.html 계산 (화면·엑셀·인쇄·하루 어싸인표) | 약 30초 |
| `CHROME=… node scripts/test_assign_e2e.mjs` | 실제로 눌러 끝까지 | 약 1분 |
| `CHROME=… node scripts/test_assign_compat.mjs` | 옛 배포본의 데이터 파일이 그대로 열리는지 | 약 30초 |
| `CHROME=… node scripts/test_assign_live.mjs` | 병동 양식 9가지에서 배정표를 실제로 눌러 고치고 화면·엑셀·인쇄·하루 어싸인표를 본다 | 약 30초 |

## 1. 원칙 검사 — `scripts/test_assign_principles.mjs`

### 정답은 따로 센다

검사 파일 안에 **엔진 코드를 쓰지 않는 정답**이 있다. 한 시간대(하루 D 처럼)의 문제를 받아, 손으로 정한 자리는 고정하고 차지는 차지 자리(고정 서식)
또는 허락된 자리 중 하나(102 처럼 자유)에 앉힌 뒤 **가능한 배치를 전부** 늘어놓고 가장 나은 것을 고른다. '나은 것'의 순서는 원칙 그대로다:

1. 주지 않을 방에 앉는 사람이 적다 (손으로 정한 자리와 자리 고정 서식의 차지는 세지 않는다 — 사람이 정한 것)
2. 원칙 1(어제 같은 근무) 로 이어 보는 사람이 많다
3. 원칙 2(어제 다른 근무) 로 이어 보는 사람이 많다
4. 원칙 3(쉬고 옴) 으로 이어 보는 사람이 많다
5. 원칙 1·2·3 순으로 겹친 병상이 많다

'이어 본다'는 **병실이 겹치는 것**이다. 방을 모르는 기록(지난 어싸인 직접 입력)이나 그날 방 구성이 빈 자리만 같은 자리 이름으로 본다.
꺼 둔 원칙은 등급이 없다. 원칙 3·4 를 둘 다 켜면 원칙 3 이 이긴다.

### 무작위 문제

씨앗이 고정이라 늘 같은 문제가 나오고, 실패하면 씨앗과 그날 배치가 찍힌다.

- **하루** 2만 개: 2~7명, 자리 4~6, 원칙 켜고 끄기 16가지, 차지 고정/자유(102 처럼 전부·앞 세 자리만), 방 구성(이어진 방·흩어진 방·빈 자리),
  병상수, 어제 같은 근무·다른 근무·쉬고 옴·기록 없음, 방을 모르는 기록, 차지 표시(가끔 둘), 손으로 정한 자리, 주지 않을 방(셋에 하나는 꼭).
- **한 달** 1,500 개: 5~9명이 5~10일, 순방향 교대(E→D·N→D·N→E 없음), 인원수마다 다른 방 구성, 지난 어싸인 직접 입력, 며칠의 주지 않을 방.
  엔진 결과로 '전에 본 방'을 검사 쪽에서 **따로 다시 쌓아** 매일·시간대마다 정답과 견준다.
- **차지** 3,000 개: 3~11명 + 대체간호사, 시간대별 차지 가능, /D(신규)·V, 손으로 정한 자리, 주지 않을 방, 자리 4~6.

### 보는 것

| 코드 | 내용 |
|---|---|
| E1 | 모두 한 번씩 · 자리가 빈칸 없이 · 차지가 맞는 사람 · 고정 서식이면 차지가 차지 자리 · 자유면 허락된 자리 |
| E2 | 같은 입력이면 같은 결과 |
| E3 | 꺼 둔 원칙에 해당하는 기록은 지워도 결과가 같다 — **원칙 4 가 꺼져 있으면 쉬고 온 기록은 아무 일도 안 한다** |
| E4 | 원칙 3·4 를 둘 다 켜면 원칙 3 만 켠 것과 같다 |
| E5 | 위 1~5 가 정답과 같다 |
| E6 | 원칙 4: 같은 헬퍼·같은 이어 보기로 튕김(쉬고 온 사람이 전에 보던 방)을 더 줄일 수 있는 배치가 없다 |
| E7 | 원칙 4 는 누가 헬퍼인지 바꾸지 않는다 |
| E8 | 헬퍼는 후임 — 이어 볼 것도 주지 않을 방도 없는데 선임이 헬퍼이고 후임이 앉아 있지 않다 |
| E9 | 주지 않을 방은 차지를 바꾸지 않는다 |
| E10 | 하루 근무를 바꾸면 그 앞날 배정은 하나도 안 바뀐다 |
| E11 | E5 가 같을 때 그다음 순서도 정답과 같다 — 헬퍼(선임이 헬퍼일수록 나쁘다) → 원칙 4 튕김 → 누가 잇는지(최근에 본 사람 → 선임) |
| E12 | 차지가 자리에 안 묶이는 서식(102 처럼)에서는 **누가 CRN 이든 자리는 같다** — CRN 이 차지가 아닐 때 앉았을 자리가 허락된 자리면 그 배치 그대로. 정답 = 앉은 사람 누구에게 CRN 을 줘도 그대로인 배치(딱 하나여야 한다) |
| C1~C5 | 차지는 그 근무의 정확히 한 명 · 깃발 하나 · 표시(DC·EC·NC, 둘이면 선임) → 차지 가능 최선임 → 최선임 · 대체간호사는 자격자가 있으면 차지 아님 |

차지 사람은 **주지 않을 방과 상관없이** 고른다(제1원칙 9 — 차지는 선임). 자리 고정 서식에서 차지 방에 주지 않을 방이 있으면 화면 확인 카드가 알린다.

### 원칙을 바꿀 때

원칙의 순서나 뜻을 바꾸면 **정답 쪽(`vec`·`cont`·`chargeOf`)을 먼저 고친다** — 엔진만 고치면 이 검사가 실패한다. 그게 이 검사의 목적이다.
배수를 주면 더 많이 돈다: `node scripts/test_assign_principles.mjs 3` (약 1분).

## 2. 병동별 실시간 수정 검사 — `scripts/test_assign_live.mjs`

102 문제는 **배정표에서 사람을 바꿔도 차지 자리가 따라가지 않는 것**으로 드러났다. 엔진만 보는 검사로는 화면에서 바꾸는 길(근무 바꾸기·자리 바꾸기·
대체간호사·사람 빼기)과 화면·엑셀·인쇄·하루 어싸인표가 같은 사람을 보이는지까지는 못 본다. 이 검사는 함수를 직접 부르지 않고 **사람이 하는 대로**
배정표 화면의 이름 칸·빈 칸과 이름 클릭 창의 단추를 실제로 누른다.

### 양식 9가지

| 양식 | 차지 | 무엇을 보려고 |
|---|---|---|
| 내장 101 | 자리 고정 (A(CN)) | 화면 인쇄까지 |
| 내장 122 | 자리 고정 (CN) | D 여섯 자리, 방 세 열 |
| 내장 102 | 자리에 안 묶임, 종이에 /CRN | 102 오류가 났던 곳 |
| 내장 82 | 자리에 안 묶임, 종이에 안 찍음 | SU 칸, 자리보다 사람이 많은 날 |
| 올린 102 (D 맨 아래가 D(CRN)) | D 만 자리 고정, E·N 은 안 묶임 | 화면 줄 순서 = 종이 줄 순서 |
| 올린 101 (CN 이 둘째 줄) | 자리 고정 (CN 줄) | 자리 이름·순서를 종이에서 |
| 102 자리표시자 양식 | 자리에 안 묶임 | 자리표시자로 채우는 길 |
| 92병동 양식 (82 모양) | 자리에 안 묶임 | 병동이 올린 양식 = 자동 맵핑 |
| 72병동 양식 (102 모양) | 자리에 안 묶임, 종이에 /CRN | 병동이 올린 양식 = 자동 맵핑 |

올린 양식은 관리 > 배정표 양식의 [양식 검사] → [이 양식 쓰기] 를 그대로 탄다.

### 장면과 수정

12명(차지 못 하는 사람 둘) + 신규 한 명(프리셉터와 같은 근무에 /D·/E·/N) + 82 모양은 SU 두 명. 두 주 근무표는 사흘씩 같은 사람이 같은 근무이고
(이어지는 날이 있어야 E7 이 볼 것이 있다), 날마다 근무마다 20% 는 DC·EC·NC 표시가 있다(가끔 둘). 씨앗이 고정이라 늘 같은 순서로 고친다.

수정은 양식마다 30번 무작위로: 근무 바꾸기(D·E·N·DC·EC·NC·OF·V) · 자리 맞바꾸기 · 자동으로 되돌리기 · CRN 맡기기 · 쉬는 간호사 넣기(이름 창과 빈 칸 둘 다) ·
대체간호사 넣기·빼기 · 이 날 교체 모두 풀기 · 효력 없는 교체 지우기 · 되돌리기(Ctrl+Z).

### 보는 것 (수정할 때마다 두 주 전체)

| 코드 | 내용 |
|---|---|
| E1 | 그 날 그 근무의 근무자(근무표 + 대체간호사)가 모두 한 번씩 앉는다 |
| E2 | 차지 표시가 정확히 한 사람 |
| E3 | 자리가 앞에서부터 빈틈없이 |
| E4 | 손으로 옮긴 자리는 그대로 (맞바꾼 상대가 빠졌거나 근무가 바뀐 교체는 효력 없음) |
| E5 | 차지 = 규칙. 근무표에서 바로 센다: DC·EC·NC 표시(둘이면 선임) → 차지 가능 최선임 → 최선임. 차지 자리가 고정이면 손으로 차지 자리에 앉힌 사람이 먼저이고, 다른 자리에 손으로 앉힌 사람은 빼고 고른다 |
| E6 | 차지 자리가 고정이면 차지는 그 자리 |
| E7 | **이틀 연속 같은 사람이면 자리도 같다** — 차지가 자리에 안 묶이는 서식은 차지가 바뀌어도. 새 차지가 어제 종이 밖 자리(양식 줄을 넘는 자리)였으면 그 사람과 밀려나는 한 사람만 옮긴다 |
| S1~S3 | 화면 줄의 자리 이름 = 엔진 자리의 종이 이름 · /CRN 은 차지가 자리에 안 묶일 때 차지에게만 · 종이에 찍히는 사람은 화면에도 |
| X0~X4 | 엑셀 = 화면 (자리 이름 줄마다 같은 사람, 122 는 줄 순서로) · 엑셀 /CRN 은 서식이 찍을 때(102 모양)만 · /CRN 은 신규 줄 앞 · 신규 줄이 화면과 같다 · SU 줄은 SU 근무 |
| P1·P2 | 인쇄(101 모양) = 화면 — 줄 순서도 |
| H1~H3 | 하루 어싸인표(hwpx) 줄 = 엔진 자리 · /CRN 은 화면과 같은 사람 · /CRN 은 신규 줄 앞 |
| O1~O7 | 누른 단추가 한 일 — 맞바꾼 자리로 갔다 · 차지가 자리에 안 묶이면 맞바꿔도 차지 그대로 · CRN 맡기기·DC 로 바꾸기 뒤 그 사람이 차지 · **CRN 을 바꿔도 아무도 자리를 옮기지 않는다**(CRN 이 종이 자리에 있었으면. 앞 CRN 이 차지가 아니면 종이 밖 자리였을 사람이면 그 사람은 제자리로 가고, 밀려났던 사람들이 돌아온다) · 자동으로 되돌리기·교체 모두 풀기가 고정을 푼다 · 대체간호사가 들어갔다 |
| U1·U2 | 되돌리기(Ctrl+Z)는 바로 전 수정 전으로 · 바뀐 수정은 되돌리기 기록이 있다 |

실패하면 양식·코드·날짜와 **마지막 12번의 수정 순서**가 찍힌다. 같은 씨앗으로 다시 돌리면 같은 순서로 고친다:
`node scripts/test_assign_live.mjs --seed 1 --only 102 --ops 60` (`--only` 는 양식 이름의 일부, `VERBOSE=1` 이면 통과해도 순서를 찍는다).
씨앗과 횟수를 늘려 가끔 더 돌린다 — CI 는 씨앗 1·30번이다. 2026-10-01 에 씨앗 2~16 을 80번씩 더 돌려 모두 통과했다.

### 처음 돌렸을 때 찾은 것 (2026-10-01)

- 올린 양식(자리 이름·순서가 내장과 다른 양식)에서 **되돌리기(Ctrl+Z)를 누를 때마다** 화면이 내장 양식 이름(A(CN)·B…)으로 그려졌다 — 되돌리기가
  양식 캐시를 지웠고, 다시 읽은 뒤에는 자리 이름·순서가 바뀐 것을 '다시 그릴 일'로 치지 않았다. 양식이 실제로 바뀐 되돌리기만 다시 읽고,
  자리 이름·순서도 다시 그릴 일로 친다(`seatSig`). 처음 열 때(양식을 다 읽기 전에 그린 화면)도 같은 길을 타므로 함께 고쳐진다(코드로 확인 — 화면으로 재현해 보지는 않았다).
- 인쇄(101 틀)는 줄을 늘 차지·A·B… 순서로 그렸다 — CN 이 둘째 줄인 올린 101 양식은 화면·엑셀과 줄 순서가 달랐다. 화면과 같은 순서(`weekSlots`)로.
- 102·82(차지가 자리에 안 묶이는 서식)에서 **CRN 맡기기를 누르면 다른 사람들 자리가 바뀌는 날**이 있었다 — /CRN 은 사람에 붙는데 자리가 따라 움직였다.
  엔진이 CRN 자리를 고를 때 '어제와 같은 자리 이름'을 '차지가 아닐 때 앉았을 자리'보다 먼저 봤고, 허락된 빈 자리가 하나뿐이면 따져 보지도 않고
  거기 앉혔다. 이제 CRN 이 차지가 아닐 때 앉았을 자리가 허락된 자리면 **그 배치를 그대로** 쓴다(누가 CRN 이든 같은 배치). 원칙 검사 E12 가 이것을 모든 경우로 본다.
  남는 경우 하나: 사람이 양식 칸보다 많아 종이 밖 자리가 있는 날, 종이 밖이었을 사람을 CRN 으로 정하면 그 사람은 종이 자리로 올라오고 한 사람이 밀려난다.
  CRN 을 다시 넘기면 제자리로 돌아간다 — 맞는 결과다.
