근무표 작성 순서

설정 (첫 1회)

헤더 톱니바퀴 → 간호사 등록 → 요일별 필요인원 설정 → 규칙 관리

① 사전입력

주휴(주) → 연차(V) → 생리휴가(생) → 희망 근무 순으로 입력. 빈 셀은 자동 배정이 채웁니다.

② 분석

인원 과부족 확인 → 주휴 추천 배분 → "사전입력에 적용" 클릭

③ 근무표 생성

"근무표 만들기" 클릭 → 자동 배정이 근무표를 만듭니다 (5~20분 소요). 안 나오면 "사전입력 완화" 체크 후 재시도

④ 확인 · 저장 · 내보내기

표 확인 → 셀 클릭으로 수동 수정 → 저장 → 인쇄 · 내보내기(엑셀(CSV) 파일 · 어싸인용 복사). 표 아래 요약·리포트에 원티드 미반영·오프특근·위시 반영이 정리됩니다

설정 (헤더 톱니바퀴)

  • 간호사 추가/수정/삭제 (드래그로 순서 변경)
  • 엑셀 템플릿 내려받기 → 엑셀에서 편집 → 일괄 가져오기
  • 요일별 D/E/N 필요 인원 설정
  • 하드 제약 (연속 근무, 역순 전환 금지 등)
  • 우선순위 (순방향 전환, 야간 공평 등)

✏️ 사전입력 탭

  • 셀 클릭 → 근무 선택 팝업
  • 키보드 직접 입력: D/E/N/V/O(=OF)/W(=주) + 방향키 이동
  • 드래그 선택: 여러 셀을 드래그 후 한 번에 채우기
  • 주휴 클릭 시 자동 배분 옵션 (로테이션/고정/이번만)
  • 날짜 우클릭: 법정공휴일 지정

📊 분석 탭

  • 일자별 D/E/N 필요인원 + 여유 히트맵
  • 주휴 추천 배분 → "사전입력에 적용" 한 번에 반영
  • 경고: 인원 부족/빡빡한 날짜 표시

📅 근무표 탭

  • 기본 행: 생성 · 사전입력 완화 · 연차(V) 무제한. 나머지는 고급(오차·시간·자동 배정·주휴 이동 허용·완화 설정·점수 조절)
  • 저장 / 불러오기(저장 목록 서랍 + 근무표 파일 업로드) / 내보내기(CSV·인쇄·어싸인용 복사)
  • 표 아래 요약·리포트: 원티드 미반영 · 오프특근 · 주의 · 위시 반영 · 생성 리포트 · 자동 배정 로그
  • 생성 후 셀 클릭으로 수동 수정 (빨간 테두리 표시)
  • 더보기에서 차지 표시 · 색 켜기/끄기

💾 저장 · 불러오기 (근무표 탭 안)

  • [저장]으로 보관, [불러오기]가 저장된 근무표 목록 서랍을 엽니다 (삭제 · 근무표 파일 업로드 포함)
  • 생성 완료 시 자동 저장

❓ 근무표 생성이 실패합니다

1. 사전입력 완화 체크 → 재시도
2. 실패 시 주휴 이동 허용 추가
3. 실패 시 연차(V) 무제한 추가
4. 그래도 실패 시 에러 메시지의 원인 확인 → 해당 규칙 완화 (설정 탭)

❓ 사전입력 완화란? (최소 침습)

생성이 안 될 때, 사전입력을 자동 배정이 바꿀 수 있게 허용합니다. 꼭 필요한 만큼만 바꾸며 순서는 근무 → (인원 부족 보고) → 휴무입니다. 즉 근무 배정을 먼저 조정하고, 휴무(OFF·V·생·특·공·법·병)는 간호사 개인의 시간이라 최후에만 건드립니다(주휴는 고정). 휴무가 바뀌면 ⚠로 알려주고, 처방 적용 시 확인을 받습니다. 두 계산 방식 모두 같습니다. "완화 설정"에서 보너스를 조절할 수 있습니다.

❓ 엑셀/구글시트에서 근무표를 붙여넣으려면?

사전입력 탭 → "📋 엑셀 붙여넣기" 클릭. 엑셀에서 표 영역(이름 열 + 날짜 행 + 근무 칸)을 선택해 복사(Ctrl+C)하고, 모달에 Ctrl+V로 붙여넣으면 이름·날짜를 자동 매칭하고 적용 전 미리보기를 보여줍니다. 인식 코드: D·E·N·OF·V·주·생 등(한글 별칭 "데이/이브/나이트/오프/연차"도 인식). 매칭 안 된 이름·미인식 코드는 경고로 표시되고 그 칸만 건너뜁니다.

❓ 생성 시간이 너무 오래 걸립니다

고급에서 정확도를 ‘빠르게’로 두면 훨씬 빨리 끝납니다. ‘정밀’은 가장 좋은 답을 끝까지 찾느라 오래 걸립니다.

❓ 간호사를 한번에 등록하려면?

설정 탭 → "엑셀 템플릿 내려받기" 다운로드 → 엑셀에서 편집 → "엑셀/CSV 가져오기"로 업로드

❓ 차지(차지) 순서는 어떻게 결정되나요?

간호사 목록 순서(위=선임, 아래=후임)가 시니어리티입니다. 드래그로 순서를 변경하세요. 선임이 DC/EC/NC(차지)를 우선 배정받습니다.

❓ 다크 모드는 어디서?

헤더 오른쪽의 ‘다크’ 버튼을 누르세요. 폰에서는 더보기 → 어두운 화면.

❓ 데이터는 어디에 저장되나요?

모든 프로필과 DB는 %APPDATA%\NurseScheduler\에 저장됩니다. 앱을 삭제해도 데이터는 보존됩니다.
