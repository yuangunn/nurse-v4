# 어싸인 배정표 — 단일 실행 파일 (Windows)

`어싸인배정표.exe` **하나**만 병동 공용 폴더에 두면 된다. 설치도, 브라우저도,
로컬 서버(127.0.0.1)도 없다.

## 무엇이 다른가

브라우저로 `assign.html` 을 열면(`file://`) 파일에 쓸 때마다 사용자가 파일을 고르고
"편집을 허용할까요?" 에 답해야 한다. 브라우저 보안 규칙이라 HTML 안에서는 못 없앤다.

이 프로그램은 브라우저를 띄우는 게 아니라 **자기 창 안에 렌더러(WebView2)만 얹는다.**

| | 브라우저로 열기 | 이 프로그램 |
|---|---|---|
| 주소창·탭 | 있음 | **없음** (그냥 앱 창) |
| 로컬 서버 | — | **없음** (127.0.0.1 안 씀) |
| 폴더 고르기 | 없음(자동 열림) | 없음 |
| 저장 권한 확인 | 세션마다 1번 | **없음 — 바로 저장** |
| 임시 파일 | — | **없음** (화면을 메모리에서 공급) |
| 설치 | 불필요 | 불필요 (exe 하나) |

## 어떻게 도는가

- 화면(`assign.html`, 3MB)을 exe 안에 넣고, `https://assign.local/` 이라는 가짜 주소로
  **메모리에서 바로** 공급한다 — 디스크에 풀지 않는다. 출처가 고정이라 화면 설정
  (테마 등)이 계속 남는다.
- 파일 읽기·쓰기는 화면이 `postMessage` 로 요청하고 exe 가 네이티브로 처리한다.
  브라우저의 파일 권한 확인이 아예 개입하지 않는다.
- 저장 규칙은 브라우저 방식과 같다: 임시 파일에 쓴 뒤 교체(저장 중 전원이 나가도
  원본이 안 깨짐), 다른 PC가 먼저 저장했으면 덮어쓰지 않고 물어봄, 읽을 수 없는
  파일은 절대 덮어쓰지 않음.

```
Program.cs    진입점
MainForm.cs   창 + WebView2 + 화면↔파일 다리
DataFile.cs   데이터 파일 읽기·쓰기 (원자적 저장, 충돌 판정)
build.cmd     Windows 에서 빌드
build.sh      macOS/Linux 에서 윈도우용으로 빌드
```

## 빌드

```bat
REM 준비 (한 번만)
winget install Microsoft.DotNet.SDK.8

REM 리포 루트에서 화면 최신화
node scripts\build-assign-standalone.mjs

REM 빌드
standalone\app\build.cmd
```

결과: `standalone\app\dist\어싸인배정표.exe`

| 방식 | 크기 | 조건 |
|---|---|---|
| `build.cmd` (기본) | 약 68MB | 아무 Windows PC에서 실행 — .NET 설치 불필요 |
| `build.cmd lite` | 약 4MB | .NET 8 데스크톱 런타임이 깔린 PC 전용 |

68MB 인 건 .NET 런타임을 통째로 품기 때문이다. WinForms 는 트리밍(불필요한 코드 제거)을
지원하지 않아 이보다 줄일 수 없다. 더 작게 가려면 `lite` 로 빌드하고 런타임을 따로 깔거나,
같은 구조를 C++/Rust 로 다시 쓰면 4MB 안팎이 된다(화면↔파일 규약이 단순해서 이식은 가능).

## 쓰는 법

1. `어싸인배정표.exe` 를 병동 공용 폴더(NAS)에 둔다.
2. 두 번 누르면 배정표 창이 바로 뜬다. 고치면 그대로 저장된다.
3. 데이터 파일은 기본으로 **exe 옆 `assign-data.json`**. 다른 곳을 쓰려면 exe 옆에
   `assign.ini` 를 만든다:
   ```ini
   data=\\nas\간호부\5A병동\assign-data.json
   ```
   창 안에서 ⚙ 관리 > 데이터 파일 > [다른 데이터 파일 고르기] 로 바꿔도 된다.

명령줄:
```
어싸인배정표.exe                        기본 데이터 파일
어싸인배정표.exe "\\nas\5B\B병동.json"   데이터 파일 지정 (병동별 바로가기 만들 때)
어싸인배정표.exe --dev                  개발자 도구·우클릭 메뉴 켜기
```

## 알려진 걸림돌

- **WebView2 런타임**: Windows 11 에는 기본 포함, Windows 10 도 Edge 와 함께 들어와 있어
  대부분 이미 있다. 없으면 실행 시 안내 창이 뜬다
  (정보팀에 "Microsoft Edge WebView2 Runtime" 요청).
- **서명 없는 exe**: SmartScreen 경고, AppLocker/EDR 차단 가능. 코드 서명 인증서를 받거나
  정보팀에 해시 화이트리스트를 요청하는 게 정석. 그 전까지는 `file://` + 자동 열림
  (`assign-data.js`) 방식이 통과율이 높다 — 두 방식은 **같은 데이터 파일을 공유**한다.
- **NAS 경로**: 그 PC 에서 해당 경로가 보여야 한다(드라이브 매핑 또는 UNC 권한).
