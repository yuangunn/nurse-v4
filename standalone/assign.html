데이터 파일을 열면 바로 이번 주 배정표가 나옵니다.
· 파일은 공용 폴더(내부망 NAS)에 두면 어느 컴퓨터에서나 같은 내용을 봅니다.
· 브라우저가 "파일을 볼 수 있도록 허용하시겠습니까?" 라고 물으면 허용을 누르세요.
· 데이터 파일(.json)을 이 창에 끌어다 놓아도 열립니다.
이름 클릭 = 담당 교체 · 맨 윗줄(교육·행사) 클릭 = 내용 입력 · 빨간 밑줄 = 수동으로 바꾼 칸
1. 엑셀에서 근무표를 마우스로 긁어 복사하세요 (Ctrl+C)
2. 이 창을 클릭한 다음 Ctrl+V 를 누르세요
엑셀 파일(.xlsx)을 이 창에 끌어다 놓아도 됩니다. 이름 열과 날짜 줄은 자동으로 알아봅니다.
이 근무표의 시작: 년 월 — 날짜 줄에 연·월이 없으면 꼭 확인해주세요
셀 클릭 후 D/E/N/O 키 입력 · 드래그 범위 · 더블클릭 직접 입력(D/A 선입력) · Ctrl+Z
지난 어싸인 직접 입력 — 근무표에 지난 기록이 없을 때 시작점 (기록이 있으면 그쪽이 우선)
주간 배정표 파일(xlsx) 내려받기 — '병실 배정표' 양식 그대로, 엑셀에서 수정 가능
